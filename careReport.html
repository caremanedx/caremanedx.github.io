📋 ⑥ ケアの実践計画

基本方針

センター方式を活用しAさん自身の全体像を理解し、Aさんの困りごとや悩みを理解する。 離設が見られる時間帯をスタッフと一緒に過ごせるように日課として取り入れる。 台拭きなど家事の手伝いや水やりなどの役割を持ち、自分のやりたいことができるように、 ゆっくりかかわる時間を設けて気持ちの把握に努める。

① 不穏のスイッチ特定と対応統一
✓ Chat記録・不穏言動記録一覧から時間帯・直前の出来事・会話内容を分析しパターンを抽出する
✓ 判明した地雷ワード・状況はChatで全員に周知し回避・事前対応を統一する
✓ 夕方（16〜20時）は離設が集中する時間帯。デイ利用者の帰宅時間に玄関近くにいて飛び出される場面が何度もある。この時間帯のマンツーマン対応の周知徹底が必要
確認済みの地雷ワード・状況：往診後／他者の面会・外出場面／スタッフ間の会話／作業の失敗／物品紛失／デイ帰宅時間帯（夕方）
② 役割活動の継続（台拭き・水やり・掃除）
✓ 離設が見られる時間帯に合わせて役割活動を日課として取り入れる（夕方の台拭き・水やり等）
✓ 毎日継続し「できた」体験を積み重ねる。活動後は必ず感謝の言葉を伝える
「助かります」「きれいになりましたね」「Aさんが手伝ってくれると助かるよ」
✓ 活動後の表情・発言をChatに記録しチームで共有する

📖 精神訪問看護記録5/26：「個人での活動が不穏になりにくい傾向」

③ 他者比較・自己評価低下時の声かけ統一
✓ 「私はここにおらん方がいい」等の発言は否定せず傾聴する
✓ 傾聴後すぐにAさん自身の「できていること・役割」に焦点を当てた声かけに切り替える
「台拭きしてくれて助かっています」「花がきれいになりましたね」「ずっとここにいていいんですよ」
✓ ゆっくりかかわる時間を設けて気持ちの把握に努める（一対一の関わりが有効）

📖 Chat記録1/8：「ずっといていいですよ」の一言で即座に安心・笑顔が確認されている

④ 対人トラブルの予防的環境調整
✓ 苦手な利用者（食器洗い・盛り付けを生きがいとされている利用者とのトラブルあり）との接近を避ける配慮が必要
✓ デイ利用日・席の工夫でトラブルを予防する
✓ 他利用者の面会・外出場面では事前に声かけし孤独感を軽減する
⑤ Chatを活用したチーム連携
✓ 不穏言動記録一覧に実習中データを随時追記し週次でChatに共有する
✓ 有効だった声かけ・活動をChatのスレッドに一言記録する
例）「台拭き後に笑顔あり」「水やり後に落ち着いた」「今日は拒否。明日また試みる」
✓ 週次状況まとめ（📊投稿）をChatに投稿し前週比較で変化を可視化する

⚠️ ⑦ 支援内容での配慮事項

⚠️ 対人トラブルの配慮

同じ施設に食器洗いや食事の盛り付けを生きがいとされている利用者がいる。その利用者とトラブルがあったため、接近しないような配慮が必要。デイ利用日・席の配置を工夫する。

⚠️ 夕方の離設リスク（最重要）

夕方デイの利用者の帰宅時間に、玄関近くにいて飛び出される場面が何度もあった。マンツーマンでスタッフがつけることが毎日ではない。
→ この時間帯（16〜20時）の周知徹底が必要。できる限りスタッフが近くにいられるよう、この時間帯を役割活動の時間として日課に取り入れる。
